# meezan-fact-checker

مشروع مفتوح المصدر يهدف إلى تطوير أداة عربية للتحقق من الأخبار والمعلومات المتداولة على الإنترنت.  
يساعد المستخدمين على التمييز بين الأخبار الصحيحة والمضللة عبر واجهة بسيطة ومرنة، مع إمكانية التوسع لإضافة مصادر وخوارزميات أكثر تقدمًا.

## 🎯 أهداف المشروع
- تعزيز الوعي الرقمي ومكافحة الأخبار الكاذبة.
- توفير أداة مجانية وسهلة الاستخدام للمجتمع العربي.
- دعم الباحثين والمطورين في بناء حلول تعتمد على الذكاء الاصطناعي.

## 🚀 المميزات
- واجهة عربية واضحة وسهلة الاستخدام.
- إمكانية إدخال النصوص والتحقق منها مباشرة.
- قابلية التوسع لإضافة مصادر بيانات جديدة.
- تصميم يعتمد على Flutter لتوفير تطبيق متعدد المنصات.
